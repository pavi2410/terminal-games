## Installation

**uv**:

```bash
uv tool install git+https://github.com/pavi2410/terminal-games
```

**mise**:

```bash
mise use -g pipx:pavi2410/terminal-games
```

Then run the following command to start the game launcher:

```bash
terminal-games
```
